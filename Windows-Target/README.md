# Windows-Target — целевая машина (жертва)

## IP-адрес
- Внутренняя сеть: `10.10.10.4`

## Установленные компоненты
- Wazuh Agent (подключён к серверу `10.10.10.5`)
- Git (для работы с репозиторием, опционально)

## Статус подключения агента
- **Имя агента:** `Target`
- **ID:** `002`
- **Статус:** `active` (подключён и отправляет логи)
- **Версия агента:** `v4.14.7`
- **Дашборд:** доступен по адресу `https://192.168.0.28`
- **Операционная система:** Windows 10 Pro (сборка 19045.5608)

## Конфигурация
- Файл конфигурации агента: `C:\Program Files (x86)\ossec-agent\ossec.conf`
- Ключ аутентификации сгенерирован на сервере через `manage_agents` и импортирован.

## Логи и диагностика
- Лог-файл агента: `C:\Program Files (x86)\ossec-agent\ossec.log`
- Для проверки статуса на сервере: `sudo /var/ossec/bin/agent_control -lc`
